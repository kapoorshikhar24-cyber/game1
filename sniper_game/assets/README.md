# Assets Directory

This directory houses all 3D environment assets, textures, and materials for *ELITE SNIPER: SHADOWS OF INDIA*.

## Directory Layout

- `environment/`
  - `terrain/` - Heightmaps, terrain chunk GLBs
  - `rocks/` - Mountain rock & boulder GLB assets (`granite_rock_02`, `rock_boulder_01`)
  - `vegetation/` - Coniferous tree GLBs (`fir_tree_01`, `pine_tree_01`), bushes (`bush_01`), grass tufts (`alpine_grass_01`)
  - `ground/` - Ground mesh assets
  - `snow/` - Snow layer meshes
  - `mountains/` - Distant mountain HDRI skybox maps (`alpine_shelter_4k.hdr`)
- `materials/` - Shared PBR material definitions
- `textures/`
  - `ground/` - 2K Ground/Dirt PBR maps (`brown_mud_03`)
  - `snow/` - 2K Snow PBR maps (`Snow005A`)
  - `concrete/` - 2K Military Concrete PBR maps (`concrete_wall_01`)
